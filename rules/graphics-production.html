그래픽 제작 가이드

인터뷰, 시안 제작, 원격 검수, 게임 적용을 담당별로 나눠 진행한다.

담당과 인계 원본 형식 파츠 시트 목업 검수 모바일·원격 공유 게임 적용

1. 인터뷰·그래픽·구현 담당을 나눈다

인터뷰 담당
합의된 내용을 먼저 브리프에 옮기고, 외형·역할·참고 사례·동작·표시 크기 중 시안에 영향을 주는 빈 부분을 확인한다. 확정한 요구와 아직 열려 있는 선택을 구분해 그래픽·구현 담당에게 같은 브리프를 전달한다.
그래픽 담당
브리프를 바탕으로 분리 파츠와 조립본을 갖춘 검수용 시안을 완성한다. 공개 HTML 목업 링크를 사용자에게 보내고, 피드백을 반영한 뒤 승인된 시안 버전과 원본, 파츠·동작 정보를 구현 담당에게 인계한다.
기능 구현 담당
조작·판정·상태와 필요한 그래픽 연결 지점을 먼저 정리한다. 그래픽 작업과 독립적인 기능은 병렬로 개발하고, 승인된 시안을 받으면 연결한 뒤 실제 카드와 전장에서 확인한다.

브리프를 공유한 뒤 그래픽과 기능 개발을 병렬로 진행한다. 그래픽 승인 기록에는 시안 버전과 검수 링크, 사용자 의견을 함께 남겨 다음 담당자가 적용할 판본을 찾을 수 있게 한다.

2. 원본 형식 선택

SVG 파츠 시트가 기본이다. 색·윤곽·표정·장비를 도형과 경로로 수정할 수 있게 만든다. 붓 자국, 회화적 질감이나 복잡한 음영처럼 SVG로 원하는 표현을 만들기 어려우면 투명 PNG 파츠 시트를 사용한다. 이 경우 보존해야 할 표현과 선택 이유를 작업 기록에 남긴다.

기존 승인 자산을 수정할 때는 해당 자산의 원본과 파츠 구성을 기준으로 삼는다. 공통 정책은 AI-020에서 관리한다.

3. 파츠를 나누고 조립한다

몸통·팔다리·표정·장비 가운데 따로 움직이거나 교체할 요소를 독립 영역에 둔다. 파츠 이름, 조립 위치, 회전 중심과 앞뒤 순서를 기록한다. 같은 손이나 발을 좌우에서 공유하면 파츠 하나와 두 배치로 표현한다.

4. 목업에서 순서대로 검수한다

  1. 외형. 목업 페이지에서 분리 파츠, 조립 모습, 실제 카드나 전장 크기를 나란히 보여준다. 기존 목업 페이지가 있으면 같은 곳에 추가한다. 수정 작업은 바뀐 부분의 전후를 같은 크기로 비교한다.
  2. 동작. 외형 승인 후 필요한 대기·이동·공격·피격 동작을 보여준다. 파츠가 회전하는 경우 회전 중심과 몸체 앞뒤로 지나는 순간을 확인한다.
  3. 적용. 시각 검수 결과를 반영하고, 실제 게임 렌더러에서 파츠 위치·겹침·표정과 표시 크기가 승인한 목업과 맞는지 확인한다.

5. 모바일·원격 환경에 HTML 목업을 공유한다

  1. 같은 페이지에 시안을 올린다. 기존 HTML 목업 프로젝트를 재사용하고 시안 버전별로 바로 열 수 있는 구역을 추가한다. 최신 페이지에 있던 기존 시안과 그에 딸린 HTML·이미지·동작 자료도 함께 보존한다.
  2. 방문자 링크로 직접 확인한다. 관리 세션이 없는 브라우저에서 현재 공개 주소를 열어 대상 시안과 하위 이미지·동작이 뜨는지 본다. 모바일 너비에서 실제 크기, 비교 순서, 가로 넘침을 확인한다. 임시 터널 주소는 공유 직전에 최신 주소와 접속 상태를 확인한다.
  3. 링크와 확인할 부분을 함께 보낸다. 사용자에게 전달하는 주소는 인증 키가 없는 방문자용 HTTPS 링크로 한다. 변경한 부분과 이번에 검토할 항목을 짚고, 사용자 피드백이나 승인을 시안 버전에 연결해 남긴다.

6. 원본과 전투 렌더링을 구분한다

텍스처 기반 병종은 SVG와 PNG 모두 시작할 때 정해진 픽셀 크기로 준비해 공용 GPU 아틀라스에 올리고, 기존 포즈 애니메이션으로 파츠를 움직인다. 이 경우 원본 형식에 따른 비용 차이는 주로 다운로드와 시작 시 디코딩·래스터화에서 생긴다. 전투 중에는 아틀라스 크기, 파츠 수, 그리는 횟수와 같은 조건을 비교한다.
